🌷 Bloom & Co. (por Milagros De la Cruz)
-------------------
🎯 Objetivo del proyecto

Desarrollar una plataforma e-commerce para una floristería que permita a los clientes explorar productos, agregarlos a un carrito y realizar pedidos, mientras que los administradores puedan gestionar productos, categorías, usuarios y pedidos.

El proyecto tiene como objetivo practicar un flujo de desarrollo Full Stack completo, desde el análisis y diseño hasta el desarrollo, testing y deployment, simulando un entorno de trabajo profesional.

-------------------
💡 Problema

Una floristería que gestiona su catálogo y pedidos principalmente mediante redes sociales, mensajería u otros canales puede tener dificultades para centralizar la información de sus productos y organizar el proceso de compra.

-------------------
Solución
Crear una plataforma web que centralice:
- Catálogo de productos.
- Información y disponibilidad.
- Carrito de compras.
- Pedidos.
- Gestión administrativa.
